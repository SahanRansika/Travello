About the Project

A Smarter Way to Plan Your Journey

An academic software development project focused on designing a travel planning platform and applying modern backend development concepts.

Travello is a web-based travel planning and booking system developed as a practical project for the Advanced API Development module at the Institute of Java and Software Engineering (IJSE).

The project aims to provide a centralized platform where users can explore countries and destinations, discover hotels and dining options, review travel packages, arrange transport, and manage bookings.

The frontend is built using HTML, CSS, and JavaScript. The backend follows a layered architecture using Spring Boot, with separate controllers, service interfaces, service implementations, repositories, and model entities. MySQL is used as the relational database.

This project provides an opportunity to practice REST API development, application layering, database integration, authentication concepts, and maintainable software design.

Relational Database

How it works: Controllers receive HTTP requests and return responses. Service interfaces define operations, ServiceImpl implements business logic, repositories access persisted data, and model entities represent database records. DTOs carry request and response data, while security and configuration packages support the application.
Backend Workflow

Understanding the Layered Architecture

The backend separates HTTP handling, business logic, and data access to support maintainability and testing.

01

Receives API requests and handles HTTP responses.

02

Service

03

ServiceImpl

04

Performs database operations through Spring Data JPA.

05

MySQL

Stores and retrieves relational application data.
