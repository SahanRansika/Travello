ABOUT THIS PROJECT

Travello Travel & Booking System

Travello is a travel planning and booking website developed as a practical project for the Advanced API Development module at IJSE.

The project demonstrates a frontend interface for destination discovery, trip planning, hotel selection, transport preferences, and booking management.

This version is a static frontend. Backend API integration and permanent database storage can be implemented separately.
